# 공공데이터 값 조회

기존 기상 경로와 동일한 DB 없는 weatherApp 및 운영 externalRoutes에서 아래 GET 경로를 제공한다. 운영 데이터 변경·장비 제어는 수행하지 않는다.

- /api/v1/external/environment/air-quality?latitude=...&longitude=... : 에어코리아 인근 측정소 PM10·PM2.5 및 거리/주소/관측시각
- /api/v1/external/environment/wildfire-risk?pageNo=1 : 산림청 시군구 위험지수·분석시각. 페이지당 300건이며 다음 페이지를 조회할 수 있다.

## 인증·신청

서버 .env에서 AIRKOREA_SERVICE_KEY와 KFS_WILDFIRE_SERVICE_KEY를 설정한다. 기상청 키를 자동으로 다른 기관 호출에 재사용하지 않는다. 같은 공공데이터포털 일반 인증키여도 서비스별 활용신청과 권한 확인이 필요하다.

- 산불위험예보정보: https://www.data.go.kr/data/15084817/openapi.do
- 에어코리아 측정소정보: https://www.data.go.kr/data/15073877/openapi.do
- 에어코리아 대기오염정보: https://www.data.go.kr/data/15073861/openapi.do

키는 서버 비밀 설정에서만 관리하고 프론트·Git·로그에 넣지 않는다. 신규 경로에서 상위 API 오류 원문 URL/키를 응답에 포함하지 않는다.

## 대기질 처리

측정소 전체 목록을 페이지 단위로 수집한 후 WGS84 좌표(dmX=위도, dmY=경도)가 유효한 측정소 중 직선거리상 가까운 곳을 선택한다. 좌표 없는 측정소는 제외한다. 전체 목록이 불완전하면 가까운 측정소를 추정하지 않고 오류를 반환한다. 목록 캐시는 24시간, 관측값 캐시는 5분이다. 인근 측정소에 PM 자료가 없으면 다른 측정소 값을 조용히 대체하지 않는다.

관측시각은 KST로 정규화한다. 결측·음수·장비점검 플래그는 null이며 실제 0과 구분한다. 측정소 관측은 현장 연기·유해가스 직접 측정값이 아니다.

## 산불위험 처리

기존 forestPointV2 파서를 재사용한다. 빈 숫자·음수 결측값을 0으로 만들지 않도록 보완한다. 신규 수치 경로는 excludeForecast=1로 요청하고 시군구/시각/원지수를 유지한다. 기존 운영 경로의 기본 예보 포함 동작은 유지한다. 지수를 임의의 주의보/경보 등급으로 변환하지 않는다. 인증키 미설정은 503, 좌표/페이지 오류는 400, 상위 API 오류는 502로 반환한다.

## 실행·확인

기존 npm run start:weather로 실행한다. 기존 서버가 포트를 사용 중이면 해당 프로세스를 종료한 뒤 재실행한다.

```powershell
npm.cmd run check:environment -- 36.37369 127.33471
```

기상청·산림청·에어코리아 결과를 독립 출력한다. 키는 출력하지 않는다. 자동시험에서 표본을 사용한 결과는 실제 API 수신·현장 장비 실증과 구분한다. 신규 키가 없는 작업 환경에서의 미설정 응답은 실제 연동 성공이 아니다.


## 실제 노트북 응답 확인 (2026-11-14)

사용자 제공 check:environment 실행 결과에서 기상청 200(15시 KST 관측, 강수 0.5mm)과 산림청 200(230개 지역, 분석시각 원문 `2026-11-14 15`)을 확인했다. 에어코리아는 상위 HTTP 401이어서 실제 대기질 수신은 아직 성공하지 않았다. 이는 사용자 노트북 로그 기준 확인이며 작업 환경의 독립 실수신 검증과는 구분한다.

에어코리아 상위 401/403 오류는 측정소정보(AIR_STATION_AUTH_FAILED)와 대기오염정보(AIR_OBSERVATION_AUTH_FAILED) 단계로 구분해 해당 서비스의 승인 상태·키를 확인할 수 있도록 한다. 인증키와 상위 요청 URL은 출력하지 않는다.

check:environment는 목록 자료의 건수·표본 3개만 기본 출력한다. 전체 목록은 명령 끝에 --full을 붙여 확인한다. API 응답 자체는 축약하지 않는다.
